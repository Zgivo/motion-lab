# Contributing

1. Add typed metadata and declarative controls to `data/experiments.ts`.
2. Add the live stage and compact gallery rendering branches.
3. Keep the interaction understandable without a pointer-only cue.
4. Add a reduced-motion or static fallback.
5. Verify touch/resize behavior and cleanup every listener or animation loop.
6. Confirm clear interaction, sensible defaults, reset support and no console errors.
7. Run `pnpm typecheck`, `pnpm test` and `pnpm build`.
